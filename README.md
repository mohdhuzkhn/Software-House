A modern, responsive marketing website for **The Webers**, a software house offering custom software development, web design, branding, and digital marketing services. Built with React, Vite, and Tailwind CSS for a fast, mobile-friendly experience.

## ✨ About

The Webers is a technology-driven software house that crafts solutions combining creativity, innovation, and strategy to deliver impactful results for clients worldwide. We help small and medium-sized businesses (SMBs) grow by building **AI Agents** that automate customer support, sales, operations, and repetitive workflows — alongside custom software, websites, and brand design. This repository contains the source code for the company's official website — a single-page application showcasing the brand, services, portfolio, and contact information.

## ⚙️ Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/mohdhuzkhn/Software-House.git
cd Software-House

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Runs the app in development mode with hot module reloading at `http://localhost:5173`.

### Build

```bash
npm run build
```

Builds the app for production to the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```
